# LinguaMind - Bilingual NLP Text Analyzer 🧠

**Developer:** Shahriar
**Core Technology Applied:** Python (String Manipulation, NLP Logic, Arrays/Lists, Conditional Processing)

### 🎯 Project Objective
To integrate my linguistic proficiency (English and German B1) with my passion for Artificial Intelligence, I developed a fundamental Natural Language Processing (NLP) script. The goal of this project was to create a bilingual "Sentiment Analyzer". Using a custom lexical dictionary, the program scans input sentences in both English and German, processes the strings, and determines whether the emotional tone of the text is Positive, Negative, or Neutral.

### 🚀 Project Outcome
Building this analyzer introduced me to the core concepts of Natural Language Processing and text data handling. It demonstrated how basic logic and arrays can be used to simulate machine understanding of human languages. This project successfully bridged my two biggest interests—foreign languages and software development.
